# Controle Financeiro Pessoal — Android

Projeto pessoal desenvolvido em Flutter, Dart e SQLite, com o objetivo de criar um aplicativo Android para organização e acompanhamento das finanças pessoais.

O aplicativo será uma versão mobile do [Controle Financeiro Pessoal para Windows](https://github.com/euKelsey/Projeto-Pessoal-de-Controle-Financeiro), permitindo futuramente o gerenciamento e a sincronização dos dados financeiros entre computador e celular.

## Tecnologias utilizadas

- Flutter
- Dart
- SQLite
- Android Studio
- Git e GitHub

## Funcionalidades e estrutura

- Cadastro e gerenciamento de categorias
- Gerenciamento de cartões de crédito
- Controle de receitas, despesas e movimentações financeiras
- Gerenciamento de compras no cartão e faturas
- Dashboard para acompanhamento financeiro
- Armazenamento local com SQLite
- Organização do código em Models, Repositories, Services e Screens
- Sincronização futura entre Windows e Android via OneDrive

## Objetivo do projeto

Aplicar e aprofundar conhecimentos em desenvolvimento mobile, programação orientada a objetos, banco de dados, regras de negócio e arquitetura de software, utilizando Flutter e Dart para desenvolver uma aplicação financeira funcional e organizada.

**Status:** Em desenvolvimento. Estrutura inicial Flutter configurada e testada. As funcionalidades financeiras serão implementadas gradualmente.
